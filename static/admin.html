Quick guide
Answers to your first questions.

      

        
Account, model, key: what is the difference?
The provider account is your Claude, ChatGPT or Google subscription. The model is the AI you ask a question. The API key lets your application access this gateway.
Your username and password are only used to administer this console.

        
How do I connect my first account?
Under Provider accounts, click Add. Claude uses a token generated by claude setup-token. ChatGPT uses a code you enter in your browser. Google requires sign-in from the server terminal.
Then click Test: a small real request checks that the account responds and uses a little of its quota.

        
Do I need LiteLLM?
No. Pocket Relay works on its own: accounts, API keys and model access are already included.
For many keys or budgets within authorized use, you can place LiteLLM in front of Pocket Relay. LiteLLM manages user keys and calls the gateway with a dedicated key. Your applications then connect to LiteLLM. Provider terms still apply.
Keys created here do not restrict access to a particular model or account.

        
My application cannot connect
Check the URL ending in /v1, an active key and the full account/model identifier. A bare sonnet is rejected by default.
From another container on the same Compose network: http://customremote:8787/v1. From another machine, use your server's HTTPS address; localhost always means the application host.

        
I lost a key or reached my quota
A key is shown only when created. If you lose it, create a new one and revoke the old one. If it was shared accidentally, revoke it immediately.
Quotas come from the provider: creating a new key does not increase them. With an account-specific model, the gateway does not switch to another account.

        
Where does my data go?
Your requests go to the selected model's provider. Gateway accounts, sign-in data and keys are stored in the Docker volume at /data.
Keep this volume when updating and back it up. Stopping the container does not delete your accounts.
