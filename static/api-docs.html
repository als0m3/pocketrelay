Using the API

Create a key in the console, then copy the exact model name for your account.

Base URL: /v1. Authentication: Authorization: Bearer YOUR_KEY.

OpenAI-compatible routes

  • GET /v1/models — available accounts and models.
  • POST /v1/chat/completions — messages, images, PDFs, tools and JSON output.
  • POST /v1/responses — text/file input and history through previous_response_id.
  • POST /v1/completions — text completion.

All three generation routes accept stream: true to receive SSE events.

{"model":"my-account/sonnet","messages":[{"role":"user","content":"Hello!"}],"stream":false}

Key limitations

Responses history is kept in bounded memory and isolated by key. It is lost on restart. Models still run through CLIs, so some OpenAI parameters are unsupported. See the repository guides for details and session mode.
