# History provenance

PocketRelay continues the development of CustomRemote. The first 31 commits preserve the
original changes and dates, from September 22 to October 4, 2026. They cover the earlier
Python implementation and its deployment configurations.

Before publication, history was rewritten to replace the author's personal email with a
GitHub noreply address and private deployment details with examples (domains, IP addresses,
paths and account names). Some filenames and messages were adjusted, so commit identifiers
changed. The dates are not publication dates, and no past development activity was invented.

The October 6 commits introduce the Rust version, macOS app, PocketRelay name, public
documentation and an integration-test synchronization fix. The public source, documentation,
interfaces and commit messages were subsequently translated into English while retaining
the original commit dates. Translation is a publication edit, not a claim that the English
wording was written on those earlier dates.

Old configurations retained in history are unmaintained archives, not instructions for
deploying the current version. Privacy checks cover the full history; documented functional
tests cover the current code. See the [current README](../README.md) for installation and
known limitations.
