Pocket Relay for macOS — Apple Silicon preview

1. Drag Pocket Relay to Applications, then eject this disk image.
2. Open Pocket Relay from Applications.
3. If macOS blocks it, open System Settings > Privacy & Security,
   scroll to the Pocket Relay warning, choose Open Anyway and confirm.
4. Choose a username and password. Generate a password can create one for you;
   save it in your password manager before continuing.
5. Connect a provider account, test it, create an API key and copy your
   account/model identifier into an OpenAI-compatible application.

Step-by-step guide:
https://github.com/als0m3/pocketrelay/blob/main/docs/getting-started.md

No Docker, Homebrew, Python or Node.js installation is required.
An Internet connection and a compatible provider account are required.
Console: http://localhost:8788/admin
API: http://localhost:8788/v1

Closing the window keeps the service running in the menu bar.
Quit and stop the API stops the service. Launch at login is optional.
Docker is a separate installation with its own accounts and keys on port 8787.

This app is ad hoc-signed without an Apple Developer ID and is not notarized.
It is not an App Store app. Do not disable Gatekeeper globally.
Download only from this repository's Releases and compare the SHA-256 checksum.
Apple instructions: https://support.apple.com/102445

On first use of a provider, the app downloads and verifies its tool automatically.
An installation dialog shows progress and lets you retry if needed. Other provider tools
are not downloaded. Installed tools are kept with your app data for later use.
